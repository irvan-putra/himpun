JavaScript

JavaScript adalah bahasa pemrograman tingkat tinggi, diinterpretasikan, dinamis, dan multi-paradigma yang menjadi salah satu teknologi inti dari World Wide Web, bersama dengan HTML dan CSS. Ini adalah bahasa berbasis prototipe dengan fungsi berkelas satu (first-class functions), yang mendukung gaya pemrograman berorientasi objek, imperatif, deklaratif, dan fungsional. Bahasa ini didefinisikan oleh standar ECMAScript (ECMA-262), yang dikelola oleh Ecma International, dan telah berevolusi melalui berbagai edisi, yang paling baru mencapai ECMAScript 2024 (ES2024).

Berbeda dengan HTML dan CSS, yang merupakan bahasa penanda (markup) dan styling deklaratif, JavaScript adalah bahasa pemrograman multi-guna yang memungkinkan konten interaktif, dinamis, dan logika aplikasi yang kompleks secara langsung di dalam peramban web. Kemampudayaannya (ubiquity) berasal dari dukungan natif di setiap peramban web utama dan kemampuannya untuk memanipulasi Document Object Model (DOM) untuk membuat antarmuka pengguna yang responsif. Di luar peramban, JavaScript telah berkembang ke dalam pengembangan sisi server, aplikasi mobile, perangkat lunak desktop, perangkat Internet of Things (IoT), dan sistem tertanam, terutama melalui runtime seperti Node.js dan Deno.

Sejarah dan Asal-Usul

JavaScript diciptakan oleh Brendan Eich pada tahun 1995 saat ia bekerja di Netscape Communications Corporation. Bahasa ini dikembangkan dalam waktu sekitar sepuluh hari sebagai respons terhadap tekanan kompetitif dari Microsoft, yang sedang mengembangkan JScript untuk Internet Explorer. Tujuan awalnya adalah menambahkan kemampuan scripting ke dalam bahasa pemrograman Mocha (pendahulu Java) untuk memungkinkan pemrosesan sisi server. Namun, ketika model applet Java tertunda karena masalah kinerja dan keamanan, Netscape beralih ke bahasa yang ringan dan diinterpretasikan yang dapat berjalan langsung di dalam peramban untuk memungkinkan interaktivitas dasar pada halaman web.

Bahasa ini awalnya bernama "Mocha," kemudian "LiveScript," dan akhirnya dinamai "JavaScript" untuk memanfaatkan hype besar-besaran di sekitar Java saat itu. Meskipun namanya demikian, JavaScript tidak memiliki hubungan dekat dengan Java, meskipun meminjam beberapa elemen sintaksis darinya. Versi publik pertama dirilis bersama Netscape Navigator 2.0 pada tanggal 4 Desember 1995. Bahasa ini distandarkan sebagai ECMAScript oleh Ecma International pada tahun 1997 (ECMA-262). Proses standarisasi ini penuh kontroversi, melibatkan masukan signifikan dari Microsoft, Netscape, Sun Microsystems (sekarang Oracle), dan perusahaan teknologi besar lainnya, yang menyebabkan fragmentasi di mana peramban yang berbeda mengimplementasikan versi bahasa yang berbeda-beda.

Edisi pertama spesifikasi ECMAScript diterbitkan pada tahun 1997, dan edisi-edisi berikutnya memperkenalkan fitur-fitur utama seperti regular expressions, penanganan kesalahan, dan, dalam versi-versi yang lebih baru, modul, kelas, dan konstruk pemrograman asinkron. Tim Berners-Lee, pencipta World Wide Web, sering menyatakan bahwa JavaScript adalah "kesalahan terbesar" dari web karena kompleksitas yang diperkenalkannya, meskipun ia juga mengakui peran esensialnya dalam evolusi dan dominasi web.

Spesifikasi dan Standar Bahasa

JavaScript didefinisikan oleh standar ECMAScript (ECMA-262), yang menentukan sintaks dan semantik dari bahasa tersebut. Standar ini dikelola oleh Ecma International, sebuah organisasi standar yang didirikan pada tahun 1961. Nama "ECMAScript" dipilih untuk menghindari masalah merek dagang dengan kata "JavaScript," yang awalnya dimiliki oleh Netscape dan kemudian oleh Oracle. Standar ini diperbarui secara rutin, dengan edisi baru dirilis kurang lebih setiap tahun sejak tahun 2015. Edisi-edisi ini sering dirujuk berdasarkan tahun penerimanya, seperti ES2015 (ES6), ES2016, hingga ES2024.

Perombakan paling signifikan dalam sejarah bahasa ini terjadi dengan ES2015, yang juga dikenal sebagai ES6. Rilis ini memperkenalkan beberapa fitur yang ampuh, termasuk `let` dan `const` untuk variabel dengan cakupan blok (block-scoped), fungsi panah (arrow functions), template literals, kelas, modul, dan objek `Promise` untuk pemrograman asinkron. Sebelum ES2015, bahasa ini telah tetap besar-besaran statis sejak tahun 1997, dengan hanya penambahan kecil dalam ES3 (1999) dan ES5 (2009). ES5 memperkenalkan strict mode, metode array yang ditingkatkan, dan dukungan JSON, yang menjadi fondasi untuk pertukaran data dalam aplikasi web.

Aspek krusial dari spesifikasi ini adalah pemisahan antara standar bahasa dan lingkungan runtime. Standar ECMAScript tidak mendefinisikan API peramban (seperti `fetch`, `setTimeout`, atau manipulasi DOM) atau API yang spesifik untuk Node.js (seperti akses sistem file atau manajemen proses). API-API ini didefinisikan oleh W3C, WHATWG, atau implementasi runtime tertentu. Pemisahan ini memungkinkan JavaScript tetap portabel di berbagai lingkungan, mulai dari peramban hingga runtime server hingga perangkat tertanam.

Model Eksekusi dan Event Loop

JavaScript biasanya dieksekusi oleh mesin JavaScript (JavaScript engine), yang mengompilasi kode sumber menjadi kode mesin. Mesin yang paling menonjol adalah V8, yang dikembangkan oleh tim Chrome (awalnya oleh Lars Bak dan lainnya), yang menggerakkan Google Chrome, Node.js, dan Electron. V8 menggunakan pengompil just-in-time (JIT), yang mengompilasi kode yang sering dieksekusi ("hot code") menjadi kode mesin yang dioptimalkan untuk meningkatkan kinerja. Mesin-mesin lain yang terkenal termasuk SpiderMonkey (dipakai di Firefox, dikembangkan oleh Mozilla) dan JavaScriptCore (dipakai di Safari, dikembangkan oleh Apple).

Model eksekusi inti dari JavaScript adalah single-threaded (tunggal utas), yang berarti hanya satu baris kode yang dapat dieksekusi pada satu waktu dalam suatu konteks eksekusi tertentu. Model ini menyederhanakan manajemen memori dan konsistensi data dengan menghilangkan kondisi balap (race conditions) yang sering menghantui program multi-thread. Untuk menangani operasi asinkron seperti permintaan jaringan, masukan pengguna, dan timer tanpa memblokir utas utama, JavaScript menerapkan mekanisme event loop (lingkaran peristiwa).

Event loop secara terus-menerus memeriksa call stack dan antrean tugas. Ketika call stack kosong, ia menarik fungsi callback berikutnya dari antrean dan mendorongnya ke stack untuk dieksekusi. Event loop modern membedakan antara dua jenis antrean:

1. Antrean Makrotugas (Macrotask Queue): Berisi tugas-tugas seperti `setTimeout`, `setInterval`, dan callback I/O.

2. Antrean Mikro-tugas (Microtask Queue): Berisi tugas-tugas seperti callback `.then()` dari `Promise`, `queueMicrotask`, dan callback `MutationObserver`.

Mekanisme kritis dalam model ini adalah bahwa antrean mikro-tugas dikosongkan sepenuhnya sebelum event loop memproses makrotugas berikutnya. Hal ini memastikan bahwa pembaruan tertentu (seperti perubahan keadaan UI setelah resolusi Promise) terjadi lebih cepat dan dapat diprediksi. Model I/O non-blokir ini memungkinkan satu utas JavaScript untuk menangani ribuan koneksi simultan secara efisien, yang menjelaskan mengapa ia sangat cocok untuk aplikasi waktu nyata.

Jenis Data dan Sintaks Inti

JavaScript adalah bahasa berjenis dinamis (dynamically typed), yang berarti variabel tidak memiliki tipe tetap; tipenya ditentukan saat runtime. Bahasa ini memiliki tujuh tipe primitif: `undefined`, `null`, `boolean`, `number`, `string`, `symbol`, dan `bigint`. Semua nilai lainnya adalah objek. Tipe `undefined` mewakili variabel yang belum diberi nilai, sedangkan `null` mewakili ketiadaan nilai objek yang disengaja.

Tipe `number` adalah format bilangan titik apung (floating-point) presisi ganda 64-bit, yang sesuai dengan standar IEEE 754. Hal ini menyebabkan beberapa keanehan dalam aritmetika titik apung, seperti `0.1 + 0.2 !== 0.3`. Untuk mengatasi masalah presisi, tipe `bigint` (diperkenalkan dalam ES2020) memungkinkan representasi bilangan bulat dengan presisi arbitrer.

Secara sintaks, JavaScript mirip dengan C, dengan tanda kurung kurawal untuk blok dan titik koma untuk terminasi pernyataan, meskipun penggunaan titik koma bersifat opsional karena Automatic Semicolon Insertion (ASI). Fungsi adalah warga kelas satu (first-class citizens), yang berarti mereka dapat di passing sebagai argumen, dikembalikan dari fungsi lain, dan ditugaskan ke variabel. Hal ini memungkinkan pola pemrograman fungsional seperti fungsi orde-tinggi (higher-order functions) dan penutupan (closures). Penutupan terjadi ketika sebuah fungsi mempertahankan akses ke cakupan luarnya (lingkungan leksikal) bahkan setelah fungsi luar tersebut telah selesai dieksekusi. Fitur ini sangat mendasar untuk banyak pola desain JavaScript, termasuk pola modul dan variabel privat. Sejak ES2022, JavaScript juga mendukung medan kelas privat (`#field`), yang menyediakan enkapsulasi yang lebih kuat untuk arsitektur berbasis kelas.

Integrasi Web dan Ekosistem Framework

Domain utama untuk JavaScript adalah web, di mana ia berinteraksi dengan Document Object Model (DOM). DOM adalah representasi berbasis pohon dari dokumen HTML yang dapat dimanipulasi oleh JavaScript untuk mengubah konten, gaya, dan struktur halaman secara real-time. Kemampuan ini memungkinkan penciptaan aplikasi satu halaman (single-page applications/SPAs) di mana antarmuka pengguna diperbarui tanpa memerlukan muat ulang halaman penuh. Peramban menyediakan objek global (biasanya `window`) yang mengekspos berbagai API untuk berinteraksi dengan halaman, seperti timer, penyimpanan, geolokasi, dan renderisasi kanvas.
